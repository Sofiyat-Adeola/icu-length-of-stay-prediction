# ICU Length-of-Stay Prediction

## Research Question

Can patient characteristics and clinical information available early during an ICU admission be used to predict ICU length of stay?

## Data Source

This project uses the MIMIC-IV Clinical Database, developed by the MIT Laboratory for Computational Physiology and available through PhysioNet.

The full MIMIC-IV dataset will be used locally for cohort definition, feature engineering, and modelling.

The MIMIC-IV Demo dataset may be used for publicly shareable notebooks and demonstrations, such as Databricks notebooks.

## Licence and Data Access

The full MIMIC-IV dataset is not included in this repository.

Access to MIMIC-IV is subject to PhysioNet's credentialing, training, and data-use requirements. Any public examples or notebooks will use only data that can appropriately be shared, such as the MIMIC-IV Demo dataset.
